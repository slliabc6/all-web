# 当前状态

最后更新：2026-10-13（Asia/Shanghai）

## 已确定

负责人希望用 AI 加速多品牌网站生产，统一风格、高质量，并长期积累可复用资料。
第一阶段采用轻量静态站：产品展示、联系邮箱及真实表单询盘。
倾向 React 组件化与构建时输出 HTML；内容、素材和模板分离。
本机文件夹为日常资料源；负责人自行上传云盘备份。
GitHub 仓库用于可公开素材、索引、代码和智能体交接，不自动公开所有公司资料。
