# Morrow House 小批量家具示范商品库

本目录是 `Morrow House` 标杆实例的可替换内容层，包含 6 件虚构商品、4 个分类和 8 张本地 WebP 图片。所有名称、价格、SKU、库存和制作周期都是模板演示数据，不代表真实品牌或实物参数。

## 目录内容

- `products.json`：商品、价格、规格、SKU、关联商品和库存展示字段。
- `categories.json`：座椅、桌几、收纳和照明分类。
- `assets/`：首页空间图、工作室图和 6 张商品图；构建后全部随静态站复制，不请求外部图片。
- `src/assets/fonts/`：模板共用的 Manrope 与 Newsreader 本地字体，以及各自的 OFL 许可文件。

## 图片来源与使用范围

图片于 2026-10-20 使用内置 ImageGen 生成，再转为 WebP 用于本仓库的设计演示和模板复用。它们不是第三方商品照片，不应被当作真实产品证据；用于正式品牌前应由负责人确认发布范围。

生成方向如下（每条均要求无文字、无水印、无品牌标志）：

1. `morrow-house-room.webp`：编辑感住宅客厅，原灰泥墙、低矮胡桃木家具、苔绿色软垫、柔和侧光，具收藏者住所的安静故事感。
2. `workshop-process.webp`：小型家具工作室，匠人打磨胡桃木构件，木屑、手工具和温暖窗光，克制纪录片质感。
3. `fold-sofa.webp`：胡桃木外壳与天然亚麻软垫的低矮沙发，暖灰无缝背景，柔和侧光，编辑式商品摄影。
4. `vale-chair.webp`：胡桃木框架与暗红植鞣皮革吊带休闲椅，雕塑感三分之四视角。
5. `low-table-03.webp`：整块胡桃木低桌，手工柔化边缘与两只宽厚雕刻桌脚。
6. `gather-table.webp`：四人位烟熏橡木圆桌，交错基座，无可见五金。
7. `alder-cabinet.webp`：深胡桃木不对称边柜，黄铜细节与开放格。
8. `reed-lamp.webp`：深色黄铜灯杆、黑化钢底座和羊皮纸灯罩的纤细落地灯。

## 使用

站点配置 `sites/现代极简零售/site.json` 通过 `catalogId: small-batch-furniture` 使用本目录。复制目录并保持 JSON 字段结构，即可替换为另一家具品牌的商品库；图片路径相对于本目录解析。

对应首页配方为 `recipes/furniture-story.json`，可复用空间故事主视觉、工作室叙事和错落商品陈列。最终静态成品从 `exports/现代极简零售/网站成品/index.html` 打开。
